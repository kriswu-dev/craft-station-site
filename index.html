FAQ

常见问题

启动器支持哪些系统？

当前安装包面向 Windows 10 和 Windows 11。启动器需要 .NET Framework 4.6.2 或更高版本。

下载游戏版本会从哪里获取？

版本清单和游戏文件由启动器从 Minecraft 官方资源地址获取。下载速度会受网络环境影响。

可以用微软正版账号登录吗？

当前开源构建没有配置 Microsoft OAuth Client ID，因此微软正版账号登录尚未启用。需要在源码中配置自己的 Microsoft Client ID 后重新构建。

Essential 好友联机怎么用？

启动器内的一键安装入口目前支持 Minecraft 1.21.1 Fabric。Essential 的好友联机功能需要正版 Microsoft Minecraft 账号；当前构建的微软登录尚未配置。

如何卸载？会删除我的存档吗？

可在 Windows“已安装的应用”中卸载 Craft Station。卸载程序只移除启动器文件，不删除 Minecraft 游戏目录、实例或存档。
